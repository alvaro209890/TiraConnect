# 03 — Telas

Tema escuro, preto + cartões grafite, gradiente vermelho (#E63946) → azul (#3A86FF).

## Portal do Aluno (inspirado no X + Instagram)

| Tela | Conteúdo |
|---|---|
| Login | matrícula/e-mail + senha |
| Início (feed) | abas **Para você / Não lidos (n)**; **stories** de categorias (Tudo, Urgente, Provas…); cartões com autor verificado, tempo, categoria, selo URGENTE pulsante, título, texto, grade de mídias, arquivos; ações 💬 👁 ☑️; fixados no topo; ponto azul = não visto |
| Comunicado (modal) | texto completo, anexos, "Marcar como lido", discussão em árvore com selo da coordenação, responder, marcar como pergunta, excluir o próprio comentário |
| Explorar | busca + grade de categorias |
| Notificações | lista com não lidas destacadas; "marcar todas" |
| Perfil | dados do aluno, troca de senha (aviso se for provisória) |

Desktop: 3 colunas (menu · feed 600px · busca/fixados/categorias). Tablet: menu só com ícones. Celular: barra superior + **barra inferior** com 4 ícones; modais em tela cheia.

## Portal da Coordenação (menu lateral)

| Tela | Conteúdo |
|---|---|
| Login | usuário + senha |
| Painel | cartões: alunos ativos, publicados, agendados, rascunhos, perguntas sem resposta, visualizações 7d; publicações recentes |
| Comunicados | filtros (todos/publicados/agendados/rascunhos/arquivados), categoria, busca; cada item com status, público, 👁 vistos/público + barra, lidos, comentários; ações editar/fixar/publicar/arquivar/excluir |
| Editor (modal) | título, conteúdo, categoria, situação, data (futura = agendado), público (todos/série/turma/grupo), urgente, fixar, upload arrastar-e-soltar, links |
| Detalhe (modal) | conteúdo, tabela de quem viu/leu, discussão com responder/ocultar/excluir |
| Comentários | sem resposta / todos / ocultos |
| Alunos | busca, filtro por turma, novo, editar, ativar/desativar, resetar senha, importar CSV |
| Turmas e séries | criar série, turma, grupo; lista de turmas com nº de alunos |
| Equipe (admin) | usuários da equipe e níveis de acesso |
| Logs (admin) | últimos 300 eventos |
| Minha conta | troca de senha |

Celular: menu vira gaveta (☰) e há botão flutuante **+** para novo comunicado.
